# Original guided curriculum A1–C2

`course.json` is private authoring material, never a frontend asset. Each unit
contains original teaching notes, a reading, comprehension questions, controlled
grammar practice, a pragmatic dialogue and a separate listening script.

Build the additive SQL migration with `python3 scripts/build-curriculum.py`.
Generate the referenced synthetic audio with `python3 scripts/generate-audio.py`.
Neither command connects to a database. Applying SQL remains an explicit migration.
Never regenerate an already-deployed migration: author the next numbered version.

The CEFR labels describe intended practice difficulty, not external validation.
Completing these guided routes is not evidence of overall CEFR proficiency.
Free production, interaction with a speaker, and formal teacher moderation are
outside automatic marking. See `docs/CURRICULUM.md` for scope and review needs.
